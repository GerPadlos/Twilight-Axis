# Архитектура Twilight Axis

## Общая структура

```
Twilight-Axis/
├── code/                    # Основной код билда (TG/Bay12 heritage)
│   ├── __DEFINES/           # Макросы, константы, трейты
│   ├── __HELPERS/           # Вспомогательные proc'ы
│   ├── _globalvars/         # Глобальные переменные
│   ├── controllers/         # Master Controller и Subsystems
│   ├── datums/              # Датумы: скиллы, статусы, реагенты, флавы
│   ├── game/                # Игровой мир: области, объекты, турфы
│   ├── modules/             # Модули: мобы, профессии, одежда, магия...
│   ├── _compile_options.dm  # Флаги компиляции
│   └── world.dm             # Точка входа
├── modular_twilight_axis/   # Модули проекта Twilight Axis
│   ├── code/                # Код модулей
│   ├── icons/               # Иконки модулей
│   ├── sound/               # Звуки модулей
│   ├── lore/                # Лор-контент (расы, боги, языки)
│   ├── awful_artillery/     # Артиллерия
│   ├── church_classes/      # Церковные классы
│   ├── firearms/            # Огнестрел
│   └── ...
├── modular/                 # Сторонние/наследованные модули
│   ├── Neu_Food/            # Новая система еды
│   ├── Neu_Farming/         # Новая система фермерства
│   ├── Creechers/           # Существа
│   └── ...
├── _maps/                   # Карты (.dmm, .json, шаттлы, шаблоны)
├── icons/                   # Глобальные иконки
├── sound/                   # Глобальные звуки
├── strings/                 # Текстовые данные (имена, акценты, книги)
├── tgui/                    # UI на React
├── tools/                   # Инструменты сборки, скрипты
├── config/                  # Конфиги сервера
├── SQL/                     # SQL-схемы и миграции
├── html/                    # HTML-шаблоны для браузера BYOND
├── interface/               # .dmf скины, шрифты, стили
├── bin/                     # batch-скрипты запуска
├── docs/                    # Дизайн-документы
└── roguetown.dme            # Главный файл среды DreamMaker
```

## Язык и движок

- **Язык:** DM (DreamMaker), диалект процедурного языка с ООП
- **Расширение файлов:** `.dm` (код), `.dmm` (карты), `.dme` (среда), `.dmf` (интерфейс)
- **Компилятор:** DreamMaker (входит в BYOND)
- **Среда выполнения:** DreamDaemon (сервер), DreamSeeker (клиент)
- **Версия BYOND:** 516.1666 (CI), минимум 514

## Организация кода в `code/`

### `code/__DEFINES/` (~150 файлов)
Центральное хранилище констант. Ключевые файлы:
- `traits.dm` — все трейты (более 900 строк). Каждый трейт — строковый дефайн.
- `combat.dm` — константы боя, клик-CD, интенты.
- `mob_defines.dm` — флаги мобов, слоты инвентаря.
- `skills.dm` — константы скиллов.
- `roguetown.dm` — общие дефайны проекта.
- `MC.dm` — Master Controller дефайны.
- `balloon_alert.dm` — дефайны для балун-алертов.

### `code/controllers/`
- `master.dm` — Master Controller, управляет tick'ами.
- `subsystem/` — подсистемы (процессинг):
  - `mobs/` — обработка мобов
  - `movement/` — движение
  - `processing/` — таймеры, химия, растения
  - `rogue/` — рогутаун-специфичные (regional threat, role handler)

### `code/datums/`
Датумы — объекты без физического представления в мире.
- `skills/` — скиллы и опыт
- `status_effects/` — баффы/дебаффы
- `stress/` — система стресса
- `character_flaw/` — недостатки персонажа
- `reagents/` — химические реагенты
- `mind.dm` — "разум" персонажа (скиллы, память, антагонисты)

### `code/modules/`
Основной игровой контент:
- `mob/living/` — мобы, их жизненный цикл, движение, бой
- `mob/dead/` — призраки, наблюдатели
- `jobs/` — профессии и роли
- `clothing/` — одежда, броня
- `reagents/` — химия, зелья, еда
- `spells/` — магические заклинания
- `crafting/` — крафт
- `roguetown/` — специфичные механики Roguetown (карты, крафт, профессии, машины)
- `projectiles/` — стрелковое оружие
- `admin/` — админские инструменты
- `client/` — клиентские вещи (преференсы, ключи)

## Карты (`_maps/`)

- `_basemap.dm` — базовая карта
- `map_files/` — основные карты мира
- `templates/` — шаблоны для загрузки
- `shuttles/` — шаттлы
- `dun_world.dm` / `dun_world.json` — конфигурация подземелий
- `rockhill.dm` / `rockhill.json` — основной мир

## UI

- **tgui/** — современный UI на React/TypeScript. Сборка через `tgui-build.cmd` (Yarn PnP).
- **interface/** — классический BYOND интерфейс (`.dmf`), шрифты, стили.
- **html/** — старые HTML-шаблоны для админ-панелей, голосований и т.д.
